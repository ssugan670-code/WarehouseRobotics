SAMPLE TASKS FOR PHASE 3
========================
Copy one line at a time into the MATLAB Command Window.
Start first:   cd C:\WarehouseRobotics\src\Phase3 ; addpath(pwd) ; phase3
Use ONE set per run. There are 10 manual sets (M1 to M10) and 10 batch sets (B1 to B10). Wait for the 3-D window and the 2-D map before you type.

Notes
 - Commands with "order any" take any box that is stored on a shelf, so they work in every layout.
 - D01, D02, ... are the staging stands. A "move" command takes the box from that stand
   and puts it into the named shelf slot. Type  p3 wms  to see boxes, stands and free slots.
 - If a slot is already occupied, choose another slot name (shelves 4 to 7 have P01 to P08).
 - Robot names: red, blue, green, black, pink, yellow.
